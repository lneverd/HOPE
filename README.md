# AGI-HOPE

Official implementation of **AGI-HOPE: Mask-Guided Appearance Decoupling and Geometry-Aware Interaction Modeling for Hand-Object Pose Estimation**.

AGI-HOPE is an RGB-D framework for joint 3D hand pose and 6D object pose estimation. It decouples hand and object appearance features and models their local geometric interactions using depth-derived point clouds.
